# minisat-for-Windows
This repository produces statically linked x64 Windows binaries of [Minisat](https://github.com/niklasso/minisat).<br>

# Download
Download from [Releases page](https://github.com/PolarGoose/minisat-for-Windows/releases).<br>
The archive contains two executables:
* `minisat_core.exe` - A core version of the solver
* `minisat.exe` - An extended solver with simplification capabilities (the original name is `minisat_simp`)

# How to build
## Prerequisites
* Visual Studio 2022 or higher
## Build instructions
* Run `build.ps1` script
